# Sistema de Empréstimos

Aplicação web desenvolvida em Angular para cadastrar e listar empréstimos.

Aplicação web desenvolvida em Angular para controlar os empréstimos de livros de uma biblioteca, permitindo cadastrar novos empréstimos e acompanhar os que já foram registrados.

## Funcionalidades

- Cadastro de novos empréstimos por meio de formulário
- Listagem dos empréstimos cadastrados

## Tecnologias

- [Angular](https://angular.dev/)
- TypeScript
- HTML e CSS

## Estrutura do projeto

| Item | Tipo | Responsabilidade |
| --- | --- | --- |
| `cadastrar-emprestimo` | Componente | Formulário para cadastrar um empréstimo |
| `listar-emprestimo` | Componente | Lista com os empréstimos cadastrados |
| `emprestimo-service` | Service | Concentra os métodos usados pela aplicação (criar, listar, etc.) |
| `emprestimo` | Type | Define o formato dos objetos de empréstimo |
